# 案例：蓝色猫耳蕾姆

此案例保存用户在一次多轮设计中的最终选择及经验，只有继续该方案或寻找设计示例时才采用。它不把角色、蓝色、猫耳、画布和动作强制用于其他主题。

## 风格基准

角色来自《Re:从零开始的异世界生活》：蓝色短发遮住一只眼、女仆服、猫耳、紫粉发饰、Q 版比例。用户最终以“举起一只手、食指向上”的链接选择作为像素风参考，要求看得清人物，避免低分辨率色块混成一团。

全套共享参考色板。除后来单独要求更清晰的文本状态外，其余 16 种沿用 64px 逻辑网格。文本状态另外从高分辨率源图直接制作 128px 细节版本，并分别生成小尺寸。这个例外来自明确反馈，不应外推为所有文本光标都应不同网格。

## 最终接受的状态关系

| 状态 | 具体设计 |
|---|---|
| 文本 | 蕾姆像小猫一样趴在蓝色工字杠右侧睡觉，眼睛保持闭合；角色底与杠底每帧同一水平线；取消白色“悬空手” |
| 链接 | 蕾姆举起连着手臂的一只手，食指向上，指尖是热点 |
| 忙 | 蕾姆抱着沙漏睡觉，不加箭头 |
| 后台工作 | 保留主箭头，沙漏放右上，去掉原右下附加图标 |
| 不可用 | 蕾姆双臂交叉表示拒绝，不加箭头 |
| 笔 | 双手真正抱住笔，笔尖朝左上、笔尾在右下；热点在笔尖 |
| 精确 | 保留清楚的准星，蕾姆放右下，中心不能塞人头 |
| 个人 | 保留主手形，将右下半身像换成蕾姆 |
| 其余 | 保持各自功能方向和独立姿势，沿用已接受布局 |

箭头和工字杠更小、蓝色、轮廓略加粗，仍需在实际尺寸可辨。角色显示完整，按全部动画帧范围留边。该案例使用眨眼、呼吸和耳朵等小动作体现活泼，睡眠状态采用轻微呼吸，固定接触底线。

## 从迭代中保留的教训

- “像素风不够”不能只通过大幅降低分辨率实现。更低分辨率导致脸糊成块后，需要恢复原生细节并保持格点明确。
- 改一个状态时全套重新减色，会破坏已经接受的链接姿势。保留风格基准，精确保留其可见像素，并比对未修改产物哈希。
- “抱笔”不是把笔贴到人物身上；“趴在杠旁”也不是叠一块白色手形。必须重做支撑、接触与遮挡关系。
- 图形缩小后按比例算出的热点可能落在透明像素或隔壁角色上；要按功能层复核每个尺寸。
- 文本角色呼吸时整体上下移动会破坏底部对齐。应固定底线，只向上改变轮廓或高度。
- 所有帧必须留出空间；静帧完整不代表伸展动作不会被裁掉。
