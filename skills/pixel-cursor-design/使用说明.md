# 给那张你最喜欢的图，做一套自己的光标

这份技能可通过技能文件夹、项目规则或普通 Markdown 文档接入不同 AI Agent（目前在 Codex 是很不错的）。给 agent 参考图，可以是你的狗狗，你的推，甚至是你身边的人，然后再说：

> 请按 pixel-cursor-design 工作流，把文件夹中图片里面的人物/动物/角色做成一套像素风动态光标。

其余由 agent 完成。没有特别要求时，会依据图片的主体和颜色，制作 Windows 的 17 种状态，提供动态 ANI、静态 CUR、预览和成品压缩包。不同状态会有对应姿势和轻微动作，并检查点击位置与图形完整性。

一般情况下，用户不需要提供角色名称、动作清单、代码、尺寸或坐标。想修改时直接说“再清晰一点”“换成紫色”“文本选择让它趴着睡”啥的，按照你们自己的要求即可。

## 给不同 Agent 使用

**支持技能安装的 Agent：**在这里，你只需要解压并保留完整 `pixel-cursor-design` 文件夹，按照该 Agent 的技能导入方式安装。支持 `$pixel-cursor-design` 等专用调用方式时也可以使用，但它不是通用必需语法。

**没有技能系统的 Agent：**这里就需要你提供整个文件夹并让它先读 `START_HERE.md`；如果只能上传文档，提供同包 `PORTABLE_GUIDE.md` 和参考图，也可以粘贴该文档作为本次任务说明。无需猜安装目录或特殊命令。

**项目或自建 Agent：**将 `START_HERE.md` / `SKILL.md` 作为任务入口，按文档把现有看图、绘图、执行和文件交付工具对应起来。`agents/openai.yaml` 只是某类宿主的可选界面信息，不认识它可以忽略。

技能不绑定某个模型或图像服务。正常自动完成需要看图、绘图、像素/文件处理与真实文件交付能力；只有文字输出的模型不会因读到技能而获得这些功能。缺少能力时助手应明确说明，而不是给出虚假的“生成成功”或下载链接。技能不附带服务账号、额度和密钥。

附带 Python 工具可以在具备依赖的 Windows、macOS、Linux 或云端环境使用；没有 Python 时，具备其他等效执行工具的 Agent 也可按规范制作。接入方式不代表已经逐一实测所有 Agent/产品版本。

## 使用生成的光标

解压成品包，在 Windows 的“鼠标属性 → 指针”中选择对应状态，再点“浏览”选择相应 ANI 文件并应用。需要静态样式时选择 CUR 文件。成品包内会附状态与文件名对照。

不会自动修改你的系统设置。默认成品用于 Windows；需要其他系统时，请再上传图片时说明。
