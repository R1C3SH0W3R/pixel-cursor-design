# 通用入口：参考图生成像素动态光标

这是一套给 AI Agent 读取的工作流和可选辅助工具，不绑定某个产品的技能系统。

**使用者只需提供参考图，并说：**

> 请按照这份 pixel-cursor-design 工作流，把参考图做成整套像素风动态鼠标光标，其余由你设计，最后给我预览和成品包。

执行者收到本包后：

1. 能读取整个文件夹：读取 [SKILL.md](SKILL.md)，再按文内链接读取所需参考；路径相对本包位置解析。
2. 只能读取文档或不支持技能：读取本包 `PORTABLE_GUIDE.md`，或让使用者把它作为附件提供。它是同一套规则的单文件版本，不要求 `$技能名` 或 Slash Command。
3. 能运行 Python：可用 `scripts/probe_runtime.py` 检查本地运行时，再采用附带编码和打包工具。也可以使用宿主已经提供的等效执行能力，不必为了某个脚本更换 Agent。
4. 先根据 [能力适配](references/agent-adapters.md) 检查实际工具。能够读文档不代表能生成角色图片；不要编造工具、文件或下载链接，也不要以提示词/代码文本冒充最终光标包。

有完整看图、绘图、像素处理、二进制导出和文件交付能力时，直接制作；缺少能力时准确说明缺项并使用已有授权的替代路径。无需在制作中反复让用户选择技术参数。

`agents/openai.yaml` 是一个可选的宿主界面适配文件；不认识它的 Agent 可忽略。不要把本包冒充系统指令或用它覆盖宿主权限规则。默认产物是 Windows CUR/ANI，与 Agent 运行在 Windows、macOS、Linux 或云端无关；原生加载测试需 Windows。
